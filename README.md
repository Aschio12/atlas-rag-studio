# Atlas RAG Studio

Web UI for **Atlas**: a workspace-style dashboard (projects, agents, AI teams, automations, knowledge import), a streaming chat panel with suggestion chips and clickable citations, and a retrieval inspector that shows which chunks were retrieved, fused and reranked.

> **Status:** early development. Planned stack: Next.js (App Router), TypeScript, Tailwind, shadcn/ui, SSE streaming. No UI code is committed yet.

Backend: [atlas-rag-engine](https://github.com/Aschio12/atlas-rag-engine).

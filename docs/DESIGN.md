# Studio design direction

Derived from three reference mockups (workspace dashboard, glass chat landing, workspace/agents hub).

- **Shell:** dark collapsible sidebar plus icon rail; light content canvas; Light/Dark toggle.
- **Palette:** deep indigo-black `#1E1B2E`, violet `#7C6FD6`, lime accent `#D4F06A`, soft lavender gradients; glass cards with blur.
- **Home:** "What do you want to work on today?" collection cards with document counts, template search banner, daily activity feed.
- **Workspace hub:** tabs My Agents / AI Teams / Automations / Import; project rows with date and tag chips.
- **Chat:** glass panel, suggestion chips generated from the corpus, streaming answers, `[n]` citation chips.
- **Signature feature:** Retrieval Inspector drawer (dense, sparse, fused, reranked) and an agent step timeline.
